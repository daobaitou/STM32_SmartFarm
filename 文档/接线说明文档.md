## 数据存储

### W25Q64 SPI Flash (8MB)

| W25Q引脚 | STM32引脚 | 说明 |
|----------|----------|------|
| VCC | 3.3V | 3.3V供电 |
| GND | GND | 共地 |
| CS | PA15 | 片选（低电平选中），NOJTAG释放 |
| CLK | PB3 | SPI时钟，NOJTAG释放 |
| DI | PB4 | 数据输入(MOSI)，NOJTAG释放 |
| DO | PB5 | 数据输出(MISO) |

## 电源系统

### 双电源架构

```
12V适配器 ──→ LM2596降压(5V) ──→ STM32(3.3V LDO) + 传感器(5V)
                                        │
18650×2 (7.4V) ──→ 二极管OR电路 ────────┘
                   (市电优先)
```

| 电源 | 输出 | 说明 |
|------|------|------|
| 12V适配器 | 12V | 主电源，经降压后供电 |
| 18650×2 | 7.4V | 备用电池 |
| LM2596 | 5V | 降压模块 |
| STM32 LDO | 3.3V | 板载稳压 |

### 断电检测（LM393比较器）

| LM393引脚 | 连接 | 说明 |
|---------|----------|------|
| IN+ (输入端) | 12V分压网络 | 10K+10K分压，12V→6V |
| IN- (参考端) | STM32 3.3V | 参考电压 |
| OUT (输出端) | PA5 (GPIO_EXTI5) | 开路集电极，需10K上拉到3.3V |
| VCC | 5V | 比较器供电 |
| GND | GND | 共地 |

**分压网络：**
```
12V适配器 ──┬──→ 二极管 ──→ LM2596(5V) ──→ STM32
            │
            └──→ [10KΩ] ──┬──→ LM393 IN+
                          │
                          └──→ [10KΩ] ──→ GND (分压得~6V)
```

**检测逻辑：**
| 电源状态 | IN+电压 | OUT输出 | PA5电平 | 中断 |
|----------|---------|----------|----------|------|
| 市电正常 | ~6V > 3.3V | LOW | 低电平 | 无 |
| 市电断开 | ~0V < 3.3V | HIGH(上拉) | 高电平 | 上升沿触发 |

**响应动作：**
- 断电时：关闭风扇/窗户，长鸣500ms报警，OLED显示"BAT"
- 恢复时：短"滴"确认，OLED显示"AC"

## I2C总线共享

```
PB6 (SCL) ─┬── BH1750 (0x23)
            ├── BMP180 (0x77)
            ├── OLED SSD1306 (0x3C)
            └── DS3231 (0x68)
PB7 (SDA) ──┘
```

> 注意：多个I2C设备共用总线，地址不能冲突

---

## SPI总线

```
PB3 (CLK) ─── W25Q64 (8MB Flash)
PB4 (DI)  ─── W25Q 数据输入 (MCU→Flash)
PB5 (DO)  ─── W25Q 数据输出 (Flash→MCU)
PA15 (CS) ─── W25Q 片选
```

> 软件SPI (Mode 0)，关中断保护时序，~1MHz时钟速率
